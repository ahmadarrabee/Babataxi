# Tawseelat Al-Baba

Static RTL landing page for the Tawseelat Al-Baba taxi service.

## Files

- `index.html`
- `styles.css`
- `main.js`
- `vercel.json`
- `package.json`

## Local Preview

```bash
npm run dev
```

Then open:

```text
http://127.0.0.1:4173
```

## Deploy To Vercel

1. Push this folder to GitHub.
2. Import the repo into Vercel.
3. Leave the default static settings.

No build step is required for this site.
